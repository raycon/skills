## 1. 마침표(.)
- 서술·명령·청유문 끝에 쓴다.
- 직접 인용문 끝: 쓰는 것이 원칙, 안 쓰는 것 허용. (큰따옴표가 경계를 표시하므로)
- 명사형(`-ㅁ/-음`, `-기`)·서술성 명사로 끝나는 문장: 원칙적으로 쓰되 생략 허용. 단 이런 문장이 **연이어 나오면 앞 문장에는 반드시** 쓴다.
- `~할 것` 형태의 명령 의미: 마침표 원칙·생략 허용. (사물·일을 뜻하는 `것`에는 안 씀)
- 제목·표어: 안 쓰는 것이 원칙(꼭 필요하면 예외 허용). 두 문장으로 된 제목은 앞 문장에 마침표.
- 연월일: `1919. 3. 1.` — '일' 뒤 마침표 생략 불가(변조 우려, 쓰다 만 꼴 방지). 연·월만: `2008. 5.`, 월·일만: `7. 22.`. '연'만/'월'만/'일'만 단독으로는 마침표로 대신하지 않음.
- 특정한 날: `3.1 운동`, `8.15 광복` (마침표 원칙, 가운뎃점 `3ㆍ1` 허용). 한글로 적을 땐 부호 안 씀(`삼일 운동`).
- 장·절·항 번호 뒤: `1. 연구 목적`, `가. 인명`. 괄호 친 번호엔 안 씀: `(1)`.
- 용어: '마침표' 대신 '온점' 사용 가능.
- 띄어쓰기: 앞말에 붙임.

## 2. 물음표(?)
- 의문문·의문 어구 끝.
- 선택적 물음이 한 문장에 이어지면 맨 끝에만, 독립적이면 각각에: `중학생이냐, 고등학생이냐?` vs `왔니? 어디서 왔니?`
- 의문 정도가 약하면 마침표 허용: `내가 찾던 행복일까.` 반어 의문문은 마침표가 흔함.
- 의심·빈정거림, 적절한 말이 어려울 때 소괄호 안에: `훌륭한(?) 성적`.
- 모르거나 불확실한 내용: `최치원(857~?)`, `(1690?~1777?)`.
- 제목·표어엔 원칙상 안 씀(특별한 의도면 예외).
- 띄어쓰기: 앞말에 붙임.

## 3. 느낌표(!)
- 감탄문·감탄사 끝.
- 감탄 정도가 약하면 쉼표나 마침표 허용: `어, 벌써 끝났네.`
- 강한 느낌의 어구·평서·명령·청유문: `청춘! 이는…`, `지금 즉시 대답해!`
- 놀람·항의의 물음: `이게 누구야!`
- 감정 실은 대답·부름: `네!`, `흥부야!`
- 제목·표어는 물음표 규정 준용(원칙상 안 씀).
- 띄어쓰기: 앞말에 붙임.

## 4. 쉼표(,)
다양한 기능을 하며, **대부분 의무가 아니라 글쓴이 판단**이다. 남용하면 오히려 방해.
- 같은 자격 어구 열거: `근면, 검소, 협동`. 쉼표 없이 분명하면 생략 가능(`봄 여름 가을 겨울`). 열거 생략 줄임표 앞엔 쉼표 안 씀(`광주, 대구, 대전……`).
- 마지막 어구 앞 '그리고' 앞에는 쉼표 안 쓰는 게 자연스러움(기능 중복).
- 짝 지어 구별: `닭과 지네, 개와 고양이`.
- 이웃 수 개략: `5, 6세기`.
- 열거 순서 어구 뒤: `첫째,`, `마지막으로,`. 단 접속부사(`그러나` 등) 뒤는 안 쓰는 게 자연스러움.
- 절 연결을 분명히 할 때(필수 아님): 연결어미로 분명하면 생략.
- 되풀이 피해 줄여 열거: `여름에는 바다에서, 겨울에는 산에서`.
- 부르거나 대답하는 말 뒤: `지은아,`, `네,`.
- `곧/즉/다시 말해/이를테면`으로 다시 설명할 때 앞말 뒤.
- 조사 없는 제시어·주제어 뒤: `돈, 돈이 인생의 전부이더냐?`
- 같은 의미 어구 반복 시 앞 어구 뒤.
- 도치문에서 도치된 어구 사이: `이리 오세요, 어머님.`
- 직접 관계 없음을 표시: `갑돌이는, 울면서 떠나는 갑순이를 배웅했다.`
- 끼어든 어구 앞뒤(줄표로 대체 가능). 끼어든 어구 안에 쉼표가 있으면 **줄표를 써야** 함.
- 특별한 효과의 끊어 읽기, 짧게 더듬는 말(`부, 부정행위`).
- 용어: '쉼표' 대신 '반점' 사용 가능. 자릿점(`100,000`)은 문장 부호 규정 대상 아님(쓰는 것 자체는 무방).
- 띄어쓰기: 앞말에 붙임.

## 5. 가운뎃점(ㆍ)
- 일정 기준으로 묶어 열거: 묶음 사이 쉼표, 묶음 안 가운뎃점.
- 짝 이루는 어구: `참ㆍ거짓`, `조사ㆍ분석`. 안 쓰거나 쉼표 허용.
- 공통 성분 줄임: `금ㆍ은ㆍ동메달`, `상ㆍ중ㆍ하위권`. 쉼표 허용.
- 한 단어로 굳은 말엔 안 씀: `선후배`, `검인정`.
- 띄어쓰기: 앞뒤 말에 붙임.

## 6. 쌍점(:)
- 표제 뒤 항목·설명: `문방사우: 종이, 붓, 먹, 벼루`.
- 희곡 대화에서 인물:대사.
- 시:분, 권:장:절, 조:항: `10:20`, `요한복음 3:16`.
- 의존명사 '대' 자리: `65:60`, `청군:백군`.
- 띄어쓰기: 앞 붙이고 뒤 띄움이 원칙. 단 (3)시각·(4)비율 용법은 앞뒤 붙임.

## 7. 빗금(/)
- 대비 어구: `먹이다/먹히다`, `금메달/은메달/동메달`.
- 단위당 수량: `100미터/초`, `1,000원/개`.
- 시행 구분: `산에 / 산에 / 피는 꽃은`. 연 바뀜은 두 번 `//`.
- 분수 용법은 규정 제외(쓰는 것 자체는 무방).
- 띄어쓰기: (1)대비·(2)단위는 붙임. 단 대비 어구가 두 어절 이상이면 띄어 쓸 수 있음. (3)시행은 띄움 원칙·붙임 허용.

## 8. 큰따옴표(" ")
- 직접 대화 표시.
- 말·글 직접 인용(혼잣말 포함, 문장 형식 아니어도): `"출입 금지 구역"`.
- 책 제목·신문 이름에도 쓸 수 있음(겹낫표 허용형).
- 띄어쓰기: 여는 것은 뒷말에, 닫는 것은 앞말에 붙임.

## 9. 작은따옴표(' ')
- 인용 속 인용: `"여러분! '시작이 반이다.'라는…"`.
- 마음속으로 한 말.
- 소제목·예술작품·상호·법률(홑낫표 허용형), 주의·강조(드러냄표 허용형).
- 띄어쓰기: 여는 것은 뒷말에, 닫는 것은 앞말에 붙임.

## 10. 소괄호(( ))
- 주석·보충: `니체(독일의 철학자)`.
- 우리말과 원어 병기: `기호(嗜好)`, `커피(coffee)`. 역방향도 준용: `嗜好(기호)`.
- 생략 가능 요소: `선생(님)`, `광개토(대)왕`.
- 희곡의 동작·분위기: `(가쁜 숨을 내쉬며)`.
- 내용 들어갈 자리: `수도는 ( )이다.`
- 항목 번호: `(1) 용모, (2) 언어`.
- 괄호와 마침표 위치: 일반적으로 마침표 등은 **괄호 앞**. 괄호 안 내용이 문장의 일부면 괄호 뒤에 쓰기도 함. 괄호 안 내용이 완결 문장이면 괄호 안에도 마침표.
- 띄어쓰기: 여는 것은 뒷말에, 닫는 것은 앞말에 붙임. 단 (4)동작·(6)항목 번호의 여는 괄호는 앞말과 띄움.

## 11. 중괄호({ })
- 같은 범주 여러 요소 세로 묶음.
- 선택 가능 항목: `학교{에, 로, 까지}`.
- 띄어쓰기: 여는 것은 뒷말, 닫는 것은 앞말에 붙임.

## 12. 대괄호([ ])
- 괄호 안 괄호의 바깥쪽: `[윤석중 전집(1988), 70쪽]`.
- 고유어 대응 한자어: `나이[年歲]`, `낱말[單語]`. 외래어·외국어 대응도 준용: `낱말[word]`.
- 원문 이해 돕는 설명·논평: `그것[한글]은…`, `[이하 생략]`, `[밑줄은 인용자]`.
- (소괄호와 차이: 대괄호는 문장·단락 등 큰 단위 보충, 소괄호는 작은 단위에도 두루.)
- 종전 `〔 〕`도 디자인·편집상 필요하면 사용 가능.
- 띄어쓰기: 여는 것은 뒷말, 닫는 것은 앞말에 붙임.

## 13. 겹낫표(『 』)와 겹화살괄호(≪ ≫)
- 책 제목·신문 이름. 큰따옴표 허용.
- 제목만 단독으로 쓸 땐 부호 없이도 가능.
- 띄어쓰기: 여는 것은 뒷말, 닫는 것은 앞말에 붙임.

## 14. 홑낫표(「 」)와 홑화살괄호(< >)
- 소제목, 예술 작품 제목, 상호, 법률·규정. 작은따옴표 허용.
- 홑/겹 중 헷갈리면 홑낫표(또는 홑화살괄호·작은따옴표)를 우선 선택.
- 띄어쓰기: 여는 것은 뒷말, 닫는 것은 앞말에 붙임.

## 15. 줄표(―)
- 제목 뒤 부제 앞뒤: `역사 바로잡기 ― 근대의 설정 ―`. 뒤 줄표 생략 가능.
- 문장 중간 끼어든 어구(쉼표 대신).
- 붙임표보다 길다(길이로 구분).
- 띄어쓰기: 앞뒤 띄움 원칙, 붙임 허용.

## 16. 붙임표(-)
- 차례로 이어지는 내용 묶어 열거: `도움닫기-도약-공중 자세-착지`. 단순 열거는 쉼표 가능.
- 밀접 관련 어구: `서울-북경 항로`, `원-달러 환율`. 쉼표·가운뎃점 대체 가능.
- 합성어·접사·어미 표시 용법은 규정 제외(언어학적 용법, 쓰는 것은 무방).
- 띄어쓰기: 앞뒤 말에 붙임.

## 17. 물결표(~)
- 기간·거리·범위: `9월 15일~9월 25일`, `김정희(1786~1856)`, `3~78쪽`.
- 붙임표로 대체 허용: `1786-1856`.
- '~사회, 국제~' 식 생략 용법은 규정 제외(쓰는 것은 무방).
- 띄어쓰기: 앞뒤 말에 붙임.

## 18. 드러냄표(˙)와 밑줄
- 주의·중요 부분 강조. 일반적으로는 **작은따옴표가 가장 널리 쓰이고 원칙적으로 권장**.
- 띄어쓰기: 일정하지 않음.

## 19. 숨김표(○, ×)
- 금기어·비속어: 글자 수효만큼 씀.
- 비밀·밝힐 수 없는 사항: 이 경우엔 글자 수효만큼 쓸 의무 없음(밝힐 수 없는데 글자 수를 알려주는 건 모순).
- 띄어쓰기: 일정하지 않음.

## 20. 빠짐표(□)
- 옛 비문·문헌의 분명치 않은 글자: 수효만큼.
- 글자 들어갈 자리: `아음(牙音)은 □□□의 석 자`.
- 띄어쓰기: 일정하지 않음.

## 21. 줄임표(……)
- 할 말 줄임: 줄임표로 문장이 끝나면 뒤에 마침표·물음표·느낌표(원칙).
- 말이 없음(침묵): `"……."`.
- 문장·글 일부 생략: 이 용법만 줄임표 앞뒤를 띄우고, 앞뒤에 쉼표·마침표를 쓰지 않음.
- 머뭇거림.
- 형태 허용: 가운데 여섯 점 `……`(원칙) / 아래 여섯 점 / 세 점 `…` 모두 허용. 마침표 필요한 자리엔 마침표 추가(아래 점이면 일곱 점 꼴).
- 띄어쓰기: 앞말에 붙임. 단 일부 생략 용법(3)만 앞뒤 띄움.

## 원칙 vs 허용 핵심 정리

| 항목 | 원칙 | 허용 |
|------|------|------|
| 직접 인용문 끝 마침표 | 씀 | 생략 |
| 명사형 종결 마침표 | 씀 | 생략(단독일 때) |
| 특정한 날 부호 | 마침표 `3.1` | 가운뎃점 `3ㆍ1` |
| 짝/공통성분 어구 | 가운뎃점 | 쉼표 또는 생략 |
| 책 제목 | 겹낫표/겹화살괄호 | 큰따옴표 |
| 소제목·작품·법률 | 홑낫표/홑화살괄호 | 작은따옴표 |
| 강조·주의 | 드러냄표/밑줄 | 작은따옴표(실제로 더 권장) |
| 범위 | 물결표 | 붙임표 |
| 줄표 앞뒤 | 띄움 | 붙임 |
| 빗금 시행 구분 앞뒤 | 띄움 | 붙임 |
| 줄임표 점 | 가운데 여섯 점 | 아래 여섯 점 / 세 점 |
