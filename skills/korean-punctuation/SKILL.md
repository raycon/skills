# 한국어 문장 부호 (Korean Punctuation)

국립국어원 「문장 부호」 규정(문화체육관광부 고시 제2014-0039호, 2015. 1. 1. 시행)을 근거로, AI가 생성하는 한국어 문장의 문장 부호 품질을 높이기 위한 적용 지침이다. 규정 원문 암기가 목적이 아니라, **글을 쓰는 순간 올바른 부호를 자동으로 선택하는 것**이 목적이다.

## 핵심 원칙

1. **한국어 문장에는 한국어 부호를 쓴다.** 영문 입력 습관에서 흘러나온 부호(연속 마침표 `...`, 영문 따옴표 `" "`, 영문 하이픈 `-`을 범위 표시로 쓰는 것 등)를 한국어 산문에 그대로 두지 않는다. 가장 자주 발생하는 오류군이므로 1순위로 점검한다.
2. **부호는 앞말에 붙여 쓴다(기본).** 마침표·물음표·느낌표·쉼표·가운뎃점·줄임표는 앞말에 붙인다. 띄어쓰기가 갈리는 부호(쌍점, 빗금, 줄표)는 아래 표를 따른다.
3. **원칙과 허용이 갈리면 원칙을 기본으로 쓰되, 문맥상 허용형이 자연스러우면 허용형을 쓴다.** 둘 중 하나가 "틀린" 것이 아니다. 잘못된 제3의 형태(예: 날짜 끝 마침표 누락)를 피하는 것이 핵심이다.
4. **쉼표는 의무 부호가 아니다.** 영어식으로 절·접속부사마다 찍지 않는다. 의미 구분에 필요할 때만 쓴다.

자세한 규칙과 예시는 아래 빠른 참조 표를 우선 보고, 헷갈리는 항목은 `references/full-rules.md`(부호별 전체 규정과 용례)를 확인한다.

## AI가 자주 틀리는 안티패턴 (최우선 점검)

각 항목은 `틀림 → 올바름` 형식이다.

### 1. 줄임표를 영문 마침표로 대체
- 틀림: `그러나 성공할지는...`
- 올바름: `그러나 성공할지는…….` (가운뎃점 여섯 점 `……` + 마침표가 원칙)
- 허용: `……` 대신 점 3개 `…`, 또는 아래에 찍기도 가능. 단 **마침표가 필요한 자리에는 마침표를 함께** 찍는다. 줄임표로 문장이 끝나면 뒤에 `.` `?` `!`를 붙이는 것이 원칙.
- 주의: 키보드 입력 편의상 마침표 세 개(`...`)나 점 세 개(`…`)를 허용하지만, **마침표를 연달아 두 개(`..`)** 쓰는 형태는 규정 어디에도 없다.

### 2. 영문 따옴표 / 굽은 따옴표 혼용
- 틀림: `"인용"` (영문 직선 따옴표), `'단어'`(영문 작은따옴표)
- 올바름: `"인용"`(여는 `"` 닫는 `"`), `'단어'`(여는 `'` 닫는 `'`)
- 직접 대화·인용은 큰따옴표, 인용 속 인용·마음속 말·강조는 작은따옴표.

### 3. 영문 하이픈으로 범위 표시
- 틀림: `9월 15일-9월 25일`을 기본형으로 쓰기, `2024-2025년`
- 올바름: `9월 15일~9월 25일` (물결표가 원칙). 붙임표 `-`도 허용되지만 한국어 산문에서는 물결표가 자연스럽다.
- 물결표·붙임표는 앞뒤 말에 붙여 쓴다: `1786~1856`.

### 4. 쉼표 남용 (영어식 콤마)
- 틀림: `그러나, 우리는 가야 한다.` / `발표회가 끝나면, 바로 돌아간다.`
- 올바름: `그러나 우리는 가야 한다.` (접속부사 뒤 쉼표는 기능 중복이라 안 쓰는 것이 자연스러움) / `발표회가 끝나면 바로 돌아간다.` (연결 어미로 관계가 분명하면 생략)
- 쉼표는 의미가 헷갈리거나, 끊어 읽어야 하거나, 같은 자격의 어구를 열거할 때 쓴다.

### 5. 날짜 끝 마침표 누락
- 틀림: `2024. 3. 1` (일 뒤 마침표 없음)
- 올바름: `2024. 3. 1.` — 마침표로 '년·월·일'을 대신하므로 **일 뒤 마침표는 생략 불가**. `1`만 쓰면 '3월 1'처럼 쓰다 만 꼴이 된다.
- 마침표 뒤는 띄어 쓴다: `2024. 3. 1.` (O), `2024.3.1.` (X 권장하지 않음).

### 6. 가운뎃점 자리에 영문 부호
- 틀림: `금·은·동메달`을 `금/은/동메달`이나 `금,은,동메달`(붙여)로
- 올바름: `금ㆍ은ㆍ동메달`(공통 성분 묶음, 원칙) / 허용: `금, 은, 동메달`(쉼표)
- 가운뎃점은 앞뒤 말에 붙여 쓴다.

### 7. 제목·표어에 마침표
- 틀림: `건강한 몸 만들기.`
- 올바름: `건강한 몸 만들기` (제목·표어에는 마침표를 쓰지 않는 것이 원칙)
- 단, 제목이 두 문장이면 앞 문장에는 마침표를 쓴다: `바람이 분다. 당신이 좋다`.

### 8. 명사형 종결문의 마침표
- `~함`, `~하기`, `서술성 명사`로 끝나는 문장은 마침표가 원칙이되 생략 허용.
- 단, **이런 문장이 둘 이상 이어지면 앞 문장에는 마침표를 반드시** 쓴다: `입장 가능함. 초대권을 제시할 것.`

### 9. 책·작품 제목 부호
- 책·신문 제목: 겹낫표 `「」`… 정확히는 겹낫표 `『 』`/겹화살괄호 `≪ ≫`가 원칙, 큰따옴표 허용.
- 소제목·예술 작품·법률·상호: 홑낫표 `「 」`/홑화살괄호 `< >`가 원칙, 작은따옴표 허용.
- 부호 입력이 어려운 환경에서는 따옴표 허용형을 쓰되, 책 제목엔 큰따옴표·작은 단위엔 작은따옴표로 일관성을 지킨다.

## 부호별 빠른 참조 표

| 부호 | 이름 | 주 용도 | 띄어쓰기 / 주의 |
|------|------|---------|------------------|
| `.` | 마침표 | 평서·명령·청유문 끝, 연월일, 장·절 번호 | 앞말에 붙임. 날짜는 일 뒤에도 필수 |
| `?` | 물음표 | 의문문·의문 어구 끝 | 약한 의문은 마침표 허용. 제목엔 원칙상 안 씀 |
| `!` | 느낌표 | 감탄문·감탄사·강한 느낌 | 약한 감탄은 쉼표/마침표 허용 |
| `,` | 쉼표 | 열거, 절 연결, 부르는 말, 끊어 읽기 | 의무 아님. 접속부사 뒤·연결어미 뒤 남용 금지 |
| `ㆍ` | 가운뎃점 | 묶음 열거, 짝 어구, 공통 성분 줄임 | 앞뒤 말에 붙임. 쉼표로 대체 허용 |
| `:` | 쌍점 | 표제 뒤 설명·열거, 시:분, 대 | 앞 붙이고 뒤 띄움. 단 시각·비율은 앞뒤 붙임 |
| `/` | 빗금 | 대비 어구, 단위당 수량, 시행 구분 | 대비·단위는 붙임, 시행은 띄움(원칙) |
| `" "` | 큰따옴표 | 대화, 직접 인용, 책 제목(허용) | 여는 것은 뒷말에, 닫는 것은 앞말에 붙임 |
| `' '` | 작은따옴표 | 인용 속 인용, 마음속 말, 강조 | 위와 동일 |
| `( )` | 소괄호 | 주석·보충, 원어, 항목 번호, 빈자리 | 붙임. 문장 끝 부호는 보통 괄호 앞 |
| `{ }` | 중괄호 | 여러 요소 묶음, 선택 항목 | 붙임 |
| `[ ]` | 대괄호 | 괄호 안 괄호, 고유어 대응 한자어, 원문 논평 | 붙임 |
| `『 』` `≪ ≫` | 겹낫표·겹화살괄호 | 책·신문 제목 | 큰따옴표 허용 |
| `「 」` `< >` | 홑낫표·홑화살괄호 | 소제목·작품·법률·상호 | 작은따옴표 허용 |
| `―` | 줄표 | 부제 앞뒤, 끼어든 어구 | 앞뒤 띄움 원칙, 붙임 허용. 붙임표보다 길다 |
| `-` | 붙임표 | 차례 연결, 밀접 관련 어구 | 앞뒤 붙임 |
| `~` | 물결표 | 기간·거리·범위 | 앞뒤 붙임. 붙임표로 대체 허용 |
| `……` | 줄임표 | 할 말 줄임, 침묵, 일부 생략, 머뭇거림 | 앞말에 붙임(생략 용법만 앞뒤 띄움) |

## 적용 방식

### 글을 작성할 때
출력 직전에 위 안티패턴 8가지를 빠르게 훑어 자기 문장을 점검한다. 특히 줄임표·따옴표·범위 부호·쉼표는 영문 습관이 새어 나오기 쉬우므로 우선 확인한다.

### 교정 요청을 받았을 때
다음 형식으로 지적한다:

```
[틀린 부분] → [수정안] (근거: 어떤 규칙인지 한 줄)
```

예:
```
2024. 3. 1 → 2024. 3. 1. (연월일을 마침표로 적을 때 '일' 뒤 마침표는 생략 불가)
그러나, 시작했다 → 그러나 시작했다 (접속부사 뒤 쉼표는 기능이 중복됨)
```

원칙/허용이 모두 맞는 경우에는 "틀렸다"고 하지 말고, 더 자연스러운 쪽을 권하되 둘 다 규정상 옳다는 점을 짧게 덧붙인다.
