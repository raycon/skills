# 한국어 문장 부호

국립국어원 「문장 부호」(문화체육관광부 고시 제2014-0039호, 2015. 1. 1. 시행) 기반. 가로쓰기 24종을 다룬다. 아래 표로 부호를 선택하고, 용법이 헷갈리거나 예시나 세부 규정이 필요하면 `references/rules.md`를 읽는다.

## 부호 선택표

| 부호 | 이름 | 용법 | 띄어쓰기 |
|---|---|---|---|
| `.` | 마침표 | 평서문, 명령문, 청유문 끝, 연월일(`1919. 3. 1.`), 특정한 날(`3.1 운동`), 장이나 절, 항 번호 뒤 | 앞말에 붙임 |
| `?` | 물음표 | 의문문이나 의문 어구 끝, 의심이나 빈정거림(소괄호 안), 불확실(`857~?`) | 앞말에 붙임 |
| `!` | 느낌표 | 감탄문, 감탄사, 강한 느낌, 놀람이나 항의의 물음, 감정 실은 대답이나 부름 | 앞말에 붙임 |
| `,` | 쉼표 | 열거, 짝 구별, 절 연결, 부름과 대답, 제시어와 도치, 끼어든 어구 등 | 앞말에 붙임 |
| `·` | 가운뎃점 | 묶음 열거, 짝 어구, 공통 성분 줄임(`금·은·동메달`) | 앞뒤에 붙임 |
| `:` | 쌍점 | 표제 뒤 설명이나 열거, 대화의 인물, 시와 분, 비율(`65:60`) | 앞 붙임, 뒤 띄움(시와 비율은 앞뒤 붙임) |
| `/` | 빗금 | 대비 어구, 단위당 수량, 시 행 구분 | 대비와 단위는 붙임, 시 행은 띄움 |
| `" "` | 큰따옴표 | 대화, 직접 인용 | 안쪽 말에 붙임 |
| `' '` | 작은따옴표 | 인용 속 인용, 마음속 말 | 안쪽 말에 붙임 |
| `( )` | 소괄호 | 주석이나 보충, 원어, 생략 가능 요소, 항목 번호 | 안쪽 말에 붙임 |
| `{ }` | 중괄호 | 여러 요소 묶음, 선택 항목 | 안쪽 말에 붙임 |
| `[ ]` | 대괄호 | 괄호 안 괄호, 고유어 대응 한자어(`나이[年歲]`), 원문 논평 | 안쪽 말에 붙임 |
| `『 』` `≪ ≫` | 겹낫표, 겹화살괄호 | 책 제목이나 신문 이름 (큰따옴표로 대체 가능) | 안쪽 말에 붙임 |
| `「 」` `< >` | 홑낫표, 홑화살괄호 | 소제목, 예술 작품, 상호, 법률 (작은따옴표로 대체 가능) | 안쪽 말에 붙임 |
| `―` | 줄표 | 제목 뒤 부제 앞뒤, 끼어든 어구 | 앞뒤 띄움(붙임 허용) |
| `-` | 붙임표 | 차례로 잇는 내용, 밀접한 관련 어구 | 앞뒤에 붙임 |
| `~` | 물결표 | 기간이나 거리, 범위 (붙임표로 대체 가능) | 앞뒤에 붙임 |
| `˙`, 밑줄 | 드러냄표, 밑줄 | 강조나 주의 (작은따옴표로 대체 가능) | — |
| `○ ×` | 숨김표 | 금기어나 비속어, 비밀 사항 | — |
| `□` | 빠짐표 | 분명하지 않거나 빠진 글자 | — |
| `……` | 줄임표 | 할 말 줄임, 말 없음, 일부 생략, 머뭇거림 | 앞말에 붙임(일부 생략 시 앞뒤 띄움) |

## 참고

- 원칙형과 허용형이 함께 규정된 항목은 둘 다 옳다(종전 규정대로 써도 틀리지 않도록 허용을 넓힘).
- '마침표=온점', '쉼표=반점'으로도 부른다.
- 세부 용법과 예시, 붙임 규정, 드문 부호(숨김표, 빠짐표, 드러냄표 등)는 `references/rules.md`를 읽는다.
