# skills

Claude 에이전트 스킬 모음. [skills.sh](https://www.skills.sh) CLI로 필요한 스킬만 골라 설치한다.

## 설치

프로젝트 루트에서 아래 명령을 실행하고 새 세션을 시작한다. `--skill` 옵션으로 원하는 스킬 하나를 고른다.

```bash
npx skills add raycon/skills --skill <스킬 이름>
```

저장소의 모든 스킬을 한 번에 설치하려면 옵션 없이 실행한다.

```bash
npx skills add raycon/skills
```

CLI 없이 쓰려면 저장소를 클론한 뒤 스킬 폴더를 Claude 스킬 디렉터리에 둔다. 전역으로 쓰려면 `~/.claude/skills/`, 프로젝트 단위로 쓰려면 그 프로젝트의 `.claude/skills/`에 둔다.

```bash
git clone https://github.com/raycon/skills.git
cp -r skills/<스킬 이름> ~/.claude/skills/
```

## 업데이트

CLI로 설치했다면 스킬 파일은 `.agents/skills/`에 복사되고, `.claude/skills/`에는 그 폴더로 가는 링크가, `skills-lock.json`에는 설치한 커밋이 남는다. 저장소에 새 버전이 올라오면 프로젝트 루트에서 받는다.

```bash
npx skills update -p -y <스킬 이름>
```

설치한 스킬을 프로젝트 저장소에 함께 커밋해 두면 지금 쓰는 버전을 커밋 기록으로 알 수 있고, 문제가 생겼을 때 되돌리기 쉽다. 업데이트한 뒤에는 바뀐 내용을 확인하고 `.agents/skills/<스킬 이름>`과 `skills-lock.json`을 커밋한다.

### Obsidian

Markdown Vault(Obsidian 등)에서 쓰는 범용 스킬. 각 스킬은 노트 한 종류만 다루고 다른 스킬을 부르지 않는다. 어떤 요청에 어떤 스킬을 어떤 순서로 쓸지는 Vault의 `CLAUDE.md`에 적는다. 각 스킬은 Vault의 `CLAUDE.md`, 템플릿, 기존 노트에서 규칙을 먼저 읽고, 없을 때만 기본값을 쓴다.

```markdown
## 처리 순서

| 요청 | 처리 순서 |
| --- | --- |
| 한 일, 할 일, 일정 | `daily-note` |
| 영수증 사진 | `receipt` → `daily-note`에 구매 줄 |
| 녹음 전사 | `voice-memo` → 내용은 위 행과 같이 |
```

| 스킬 | 설명 |
|---|---|
| `daily-note` | 일일노트에 메모, 작업, 하이라이트, 일정, 구매 줄을 섹션에 맞게 기록하고, 원본 노트가 있으면 시간에 링크한다. 메모 이모지는 기본 목록이나 Vault의 목록에서 고른다. 작업의 완료, 취소, 보류는 처음 적은 노트에서 고치고 `⏳`, `✅`, `❌` 날짜를 줄 끝에 붙인다. |
| `topic-notes` | 다시 찾을 사실과 사용자의 생각을 주제마다 노트 하나에 모은다. 누가 확인해도 같은 사실은 요약하고 생각은 사용자의 말 그대로 쓰며, 값이 바뀌면 이전 값을 변경 기록에 남긴다. 요청하면 깨진 링크, 빈 노트, 겹치는 노트를 점검한다. |
| `ingest` | 정한 기간의 일일노트와 거기 링크된 원본을 다시 읽고, 주제 노트와 사람 노트로 옮길 사실, 생각, 연락을 골라 옮길 노트별 목록으로 돌려준다. 이미 옮긴 것은 거르고, 노트는 고치지 않는다. |
| `journal-review` | 일일노트로 하루 회고와 주간 회고를 한다. 기록에서 뽑은 선택지로 주제마다 하나씩 묻고, 답을 노트에 적는다. 주간 회고에서는 미완료 작업을 원래 노트에서 정리하고, 되풀이된 교훈을 주제 노트에 남길지 묻는다. |
| `voice-memo` | 음성 메모와 통화의 전사 텍스트를 원문 그대로 `raw/`에 보관하고 비밀번호, 계좌번호 등을 가린다. 원하면 영어 번역 블록을 붙인다. 내용은 녹음 날짜, 시간, 원본 링크와 함께 다음 단계로 넘긴다. |
| `people-notes` | 사람마다 노트 하나에 그 사람에 대해 알게 된 사실과 사용자의 생각을 쌓는다. 연락 자체는 일일 기록에 남기고, 동명이인을 가리고 `last_contact`, 다음 연락 할 일을 관리한다. |
| `receipt` | 영수증 사진을 판독해 영수증 노트로 남긴다. 승인번호로 중복을 거르고, 진료비는 환자와 진료 내역을 적는다. 구매를 다른 곳에 기록할 수 있게 결제일, 가맹점, 금액, 결제수단을 돌려준다. |

## 구조

각 스킬은 `skills/` 아래 자체 폴더에 들어 있고, 폴더 이름이 곧 스킬 이름이다.

```
skills/
└── <스킬 이름>/
    ├── SKILL.md          # 필수: 메타데이터와 지침
    ├── references/       # 선택: 세부 문서
    ├── scripts/          # 선택: 실행 스크립트
    └── assets/           # 선택: 설치하거나 출력에 쓰는 파일
```
